# ONE PIECE: GRAND SEA — нативная игра

## Реализовано в первом прототипе

Нативный Godot 4.7.2 (GDScript/Compatibility): парусник с визуальными парусами, океан с GPU-волнами, 56 процедурных островов на карте 30 × 30 км, Dawn Island и далёкий Laugh Tale с One Piece; плавание, ходьба по палубе и высадка; камера от третьего лица. Удалённые острова подгружаются как дешёвые силуэты, подробные острова включают растительность через MultiMesh. Несколько игроков подключаются к отдельному ENet/UDP-серверу Godot. Корабль имеет общее серверное состояние, сохранение координат и клиентскую интерполяцию.

На островах добавлены сундуки; клавиша G рядом с сундуком забирает золото. На Laugh Tale находится главный приз One Piece. Сбор наград контролирует сервер, прогресс взятых сундуков сохраняется.

Пока **не готовы** PvP, бои кораблей, NPC, сюжетные квесты, физические коллизии персонажа с деталями корпуса, инвентарь. Это технический первый прототип, не завершённая Sea of Thieves.

## Docker: сборка клиентов Windows / Linux

На одном компьютере нужны Docker Engine + Docker Compose (Docker Desktop тоже подходит). Godot вручную устанавливать не нужно.

    git clone https://github.com/swrobotcompany-dev/ONE_PIEC_vova.git
    cd ONE_PIEC_vova
    docker compose --profile tools run --build --rm builder

Нативные сборки появятся в папках dist/windows и dist/linux:

- Windows: GrandSea.exe
- Linux: GrandSea.x86_64

**Передавайте игроку всю папку целиком**, включая .pck, если он создаётся рядом с программой. Docker при первой сборке скачает Godot и официальные экспортные шаблоны. Они довольно объёмные, но загружаются лишь при создании образа.

## Docker: сервер в локальной сети

    docker compose up -d --build server
    docker compose logs -f server

Сервер слушает UDP порт 7777. Игроки запускают **отдельную игру** на ПК, нажимают JOIN FRIEND'S GAME, вводят IPv4 компьютера с Docker, например 192.168.1.100, и порт 7777.

Если соединение не работает: разрешите входящий **UDP 7777** в файрволе сервера, проверьте IP командой ipconfig (Windows) / ip addr (Linux), убедитесь, что ПК находятся в одной сети и роутер не изолирует клиентов Wi-Fi.

    docker compose down

Сохранения сервера сохраняются в папке saves.

## Без Docker

Godot 4.7.2 Standard можно распаковать без установки. Откройте project.godot и нажмите F5. Кнопка HOST GAME ON THIS PC создаст встроенный сервер. Второй игрок использует JOIN FRIEND'S GAME и LAN IP хоста.

Выделенный сервер без окна:

    godot --headless --path . -- --server --port=7777

Нельзя одновременно занимать UDP 7777 двумя серверами.

## Обновление: берег, плавание и графика

- **Корабль больше не проходит через острова.** Сервер проверяет
  перемещение небольшими шагами, учитывает запас для корпуса и при касании
  берега останавливает поступательное движение, но не запрещает поворот.
  Старые сохранения, в которых судно находилось внутри суши, исправляются
  при загрузке.
- **Разные режимы перемещения:** на суше и палубе скорость 7,5 м/с,
  в воде — 3,1 м/с с плавным разгоном. В воде персонаж держится на
  поверхности и делает гребки, на суше — шагает. Состояние плавания
  рассчитывается сервером и видно всем клиентам.
- **Высадка F:** близко к берегу — высадка на остров; вдали от берега —
  прыжок в воду рядом с кораблём. Обратная посадка возможна, если
  подплыть к судну ближе чем на 18 м и оно движется не быстрее 8 м/с.
  Сокровища в воде подобрать нельзя.
- **Графика без скачивания ассетов:** новые тона воды и блики, мелкие
  ряби, пенный след судна, светлая кромка берега, камни через MultiMesh,
  пушки и золотая отделка корабля. Режим GRAPHICS: LOW сохранён.
  Основной движок остаётся Godot Compatibility для слабых ПК.
- **Камера:** WASD идёт относительно направления камеры, а у штурвала
  A/D по-прежнему поворачивает корабль.

## Управление

| Клавиша | Действие |
| --- | --- |
| E | Сесть за штурвал / выйти из режима управления |
| W/S | Ходьба (7,5 м/с) / плавание (3,1 м/с); за штурвалом — тяга вперёд/назад |
| A/D | По палубе — шаги; за штурвалом — поворот |
| F | У берега — высадка; в море — прыгнуть в воду; у борта — подняться на корабль |
| G | Забрать сокровище у сундука в центре острова |
| Мышь | Камера от третьего лица |
| Колесо | Приближение/отдаление камеры |
| Esc | Освободить мышь |
| GRAPHICS: LOW | Сокращает количество пальм и дистанцию видимости |

У берега используется короткая безопасная высадка; вдали от берега персонаж оказывается в воде рядом с кораблём и плывёт самостоятельно.

## Архитектура и пределы

- Сервер не создаёт 3D-острова, его мир — только координаты, высота земли и состояние корабля/игроков.
- Клиенты создают острова из фиксированного seed и выгружают их вне радиуса видимости.
- Море всегда имеет ограниченный размер геометрии и следует за камерой.
- Выделенный сервер авторитетен для корабля и персонажей; обновления состояния отправляются 12 раз в секунду.
- Первый этап рассчитан на 2–8 игроков и обычные ПК: целевой 30 FPS в режиме LOW при 720p, но результаты нужно измерить на реальной машине.
- Эта первая версия **не прошла аппаратное тестирование** на целевых слабых ПК. Нужны FPS и логи для оптимизации.
