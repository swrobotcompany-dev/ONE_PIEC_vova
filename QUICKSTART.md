# ONE PIECE: GRAND SEA — нативная игра

## Реализовано в первом прототипе

Нативный Godot 4.7.2 (GDScript/Compatibility): парусник с визуальными парусами, океан с GPU-волнами, 56 процедурных островов на карте 30 × 30 км, Dawn Island и далёкий Laugh Tale с One Piece; плавание, ходьба по палубе и высадка; камера от третьего лица. Удалённые острова подгружаются как дешёвые силуэты, подробные острова включают растительность через MultiMesh. Несколько игроков подключаются к отдельному ENet/UDP-серверу Godot. Корабль имеет общее серверное состояние, сохранение координат и клиентскую интерполяцию.

На островах добавлены сундуки; клавиша G рядом с сундуком забирает золото. На Laugh Tale находится главный приз One Piece. Сбор наград контролирует сервер, прогресс взятых сундуков сохраняется.

Пока **не готовы** PvP, бои кораблей, NPC, сюжетные квесты, физические коллизии персонажа с деталями корпуса, инвентарь. Это технический первый прототип, не завершённая Sea of Thieves.

## Docker: сборка клиентов Windows / Linux

На одном компьютере нужны Docker Engine + Docker Compose (Docker Desktop тоже подходит). Godot вручную устанавливать не нужно.

    git clone https://github.com/swrobotcompany-dev/ONE_PIEC_vova.git
    cd ONE_PIEC_vova
    docker compose --profile tools run --build --rm builder

Нативные сборки появятся в папках dist/windows и dist/linux:

- Windows: GrandSea.exe
- Linux: GrandSea.x86_64

**Передавайте игроку всю папку целиком**, включая .pck, если он создаётся рядом с программой. Docker при первой сборке скачает Godot и официальные экспортные шаблоны. Они довольно объёмные, но загружаются лишь при создании образа.

## Docker: сервер в локальной сети

    docker compose up -d --build server
    docker compose logs -f server

Сервер слушает UDP порт 7777. Игроки запускают **отдельную игру** на ПК, нажимают JOIN FRIEND'S GAME, вводят IPv4 компьютера с Docker, например 192.168.1.100, и порт 7777.

Если соединение не работает: разрешите входящий **UDP 7777** в файрволе сервера, проверьте IP командой ipconfig (Windows) / ip addr (Linux), убедитесь, что ПК находятся в одной сети и роутер не изолирует клиентов Wi-Fi.

    docker compose down

Сохранения сервера сохраняются в папке saves.

## Без Docker

Godot 4.7.2 Standard можно распаковать без установки. Откройте project.godot и нажмите F5. Кнопка HOST GAME ON THIS PC создаст встроенный сервер. Второй игрок использует JOIN FRIEND'S GAME и LAN IP хоста.

Выделенный сервер без окна:

    godot --headless --path . -- --server --port=7777

Нельзя одновременно занимать UDP 7777 двумя серверами.

## Управление

| Клавиша | Действие |
| --- | --- |
| E | Сесть за штурвал / выйти из режима управления |
| W/S | По палубе — шаги; за штурвалом — тяга вперёд/назад |
| A/D | По палубе — шаги; за штурвалом — поворот |
| F | Сойти на остров рядом с кораблём / вернуться на судно |
| G | Забрать сокровище у сундука в центре острова |
| Мышь | Камера от третьего лица |
| Колесо | Приближение/отдаление камеры |
| Esc | Освободить мышь |
| GRAPHICS: LOW | Сокращает количество пальм и дистанцию видимости |

При высадке используется временная механика переноса персонажа на берег, чтобы сначала отладить LAN и движение корабля.

## Архитектура и пределы

- Сервер не создаёт 3D-острова, его мир — только координаты, высота земли и состояние корабля/игроков.
- Клиенты создают острова из фиксированного seed и выгружают их вне радиуса видимости.
- Море всегда имеет ограниченный размер геометрии и следует за камерой.
- Выделенный сервер авторитетен для корабля и персонажей; обновления состояния отправляются 12 раз в секунду.
- Первый этап рассчитан на 2–8 игроков и обычные ПК: целевой 30 FPS в режиме LOW при 720p, но результаты нужно измерить на реальной машине.
- Эта первая версия **не прошла аппаратное тестирование** на целевых слабых ПК. Нужны FPS и логи для оптимизации.


## Новые персонажи и сражения

**Tab** — переключение Луффи ↔ Зоро. **Пробел** — удар или атака мечом на острове (проверка попадания сервером). **F** — прыгнуть за борт, плавать (WASD), а при приближении вернуться на корабль. Плавание медленнее движения по земле. **G** — собрать дьявольский плод и золото в центре острова только после победы над всеми пиратами. Охранники преследуют и атакуют; после потери здоровья персонаж возрождается на судне.

Корабль не проходит сквозь берега: сервер проверяет траекторию движения по коротким шагам.

## Вес сборки и модели

Используются только два анимированных GLB KayKit Adventurers 1.0 (CC0): Rogue и Barbarian, суммарно **7.23 МБ**. На этапе сборки Docker загружает их из закреплённого коммита репозитория KayKit и включает в нативную игру. Больших текстур и полного набора персонажей нет. Подробнее: assets/characters/ASSET_LICENSE.txt.

Для разработки через редактор Godot после клонирования один раз выполните bash tools/fetch_models.sh. В Docker дополнительные действия не требуются.


## Управление, бой и обновлённая графика

- J — удар, когда персонаж находится на острове. Теперь удар имеет фазы подготовки, контакта и восстановления, сервер проверяет радиус/сектор перед персонажем, у охранника отображается HP, а в HUD считаются подтверждённые попадания.
- WASD — движение относительно камеры. Shift — ускориться на суше; в воде плавание более медленное и инерционное.
- Tab — переключить Луффи/Зоро, F — прыгнуть в воду / вернуться на судно, G — получить награду после победы над охраной.
- Ocean shader использует маску восьми ближайших островов: вода больше не должна пересекать сушу. Рядом с пляжами волны ослабевают.
- Одежда/шляпа и мечи крепятся к костям анимированного персонажа, а прежняя «вторая одежда» поверх GLB убрана.
- Острова получили больше полигонов рельефа, пальмовые листья вместо шарообразных крон, дома с окнами/дверями/крышами и смотровые башни. Корабль получил пушки, снасти, лампы, доски палубы и декор.

Тесты в Actions проверяют действия NPC/игрока, позиции и урон, не измеряя FPS реального компьютера.


## Исправления: берег, направление взгляда, стены и стрельба (Godot native)

- **Вода:** новая водная сетка вырезает окружности островов при построении геометрии; у острова физически нет водных треугольников, а старый шейдер оставлен для плавности береговой линии.
- **Камера:** зажмите **ПКМ**, чтобы вращать камеру. **WASD** двигает персонажа относительно камеры; при движении он поворачивается по направлению скорости. Для импортированных GLB-моделей исправлено направление «лица».
- **Прицел:** мышь всегда доступна. Направление на острове отмечено кольцом и полосой, **ЛКМ** стреляет в направлении курсора, а **J** делает ближнюю атаку.
- **Героические выстрелы:** Луффи выпускает оранжевый удар, Зоро — голубую режущую волну. Сервер определяет урон, скорость, попадания по пиратам и перекрытие стенами. Ограничено время между выстрелами.
- **Здания:** дома и башни теперь имеют физические коллайдеры в клиенте; сервер использует идентичный список зданий и ограничивает проникновение с возможностью скользить вдоль стены. Снаряд тоже останавливается об стены.
- **Графика Normal:** рельеф 32 × 84 сегмента, 42 пальмы на зелёном острове, больше камней, дальше видны детальные острова. Low остаётся доступным, если FPS снизится.
- Добавлены тесты вырезания океана, поворота персонажа, стен и боевых снарядов. Даже пройденные headless-тесты не заменяют визуальную проверку на вашем мониторе.


## Исправление воды, счёт и рельеф (текущая версия)

**Причина голубой воды под ногами:** предыдущий алгоритм обрезки треугольников не подходил для внешней стороны круга, поэтому части водной сетки оставались поверх берега. В новой версии вода строится адаптивными ячейками: ячейки возле береговой линии дробятся до ~1,9 м, пересекающиеся с сушей вообще не отрисовываются. Это геометрическое исправление, а не прозрачная маска.

**Очки:** за добивание враждебного пирата начисляются +100 очков и +1 убийство. Это работает с мечом, ударом и дальними атаками, определяется сервером и синхронизируется по LAN. Счёт, убийства и таблица игроков отображаются на экране. Двойная награда за одного врага исключена. Пока очки хранятся только в текущей игровой сессии.

**Разные острова:** теперь берег имеет бухты и выступы, высота определяется биомом. На карте есть тропические холмы, горные снега, вулканические кратеры, пустынные дюны, каменистые хребты, столовые горы (mesa), лагуны, джунгли и особенный остров Laugh Tale. Растительность и цвет поверхностей также различаются. Функция высоты едина для сервера и отрисовки.

В автоматические тесты добавлена проверка **каждого водного треугольника**, нескольких типов рельефа и регистрации убийств двумя игроками. Для запуска новой версии обновите **и сервер, и нативные клиенты**.


## Ноябрь 2026 — острова, разбойники, способности и управление

**Разбойники:** на каждом из 56 островов появились три типа охраны. Даже после сбора плода враги продолжают охранять остров и возрождаются через 90 секунд. На безопасном расстоянии от островов NPC не симулируются, чтобы сохранить производительность.

**Корабль:** исправлено направление поворота: **A — налево, D — направо** при движении вперёд. Обычные острова расположены гораздо ближе, а Shells Town и Orange Town находятся неподалёку от начального Dawn Island. Laugh Tale остаётся далеко.

**Дьявольские плоды:** после победы над охраной подойдите к центру острова и нажмите **G**. В зависимости от острова получите одну из способностей: **14 боевых школ плодов** (резина, огонь, лёд, молния, песок, дым, цветение, нити, свет, гравитация, магма, землетрясение, барьер, яд). Нажмите **C**, чтобы выбрать плод, и **Q**, чтобы применить его боевой приём в направлении курсора. Повторные находки повышают мастерство до уровня 4. В HUD отображаются выбранный плод, уровень и перезарядка.

**Управление:** **Space — прыжок** (двойной прыжок с плодом Цветения), **J — ближний бой**, **ЛКМ — уникальная атака героя** (резиновый кулак Луффи / пробивающая волна меча Зоро), **C — выбрать плод**, **Q — применить плод**, **Tab** — Луффи/Зоро, **ПКМ** — камера. Ранее Space был ближней атакой; теперь ближняя атака перенесена на J.

**Внешний вид:** уточнены соломенная шляпа, чёрные волосы, красный жилет, жёлтый пояс и синие шорты Луффи; зелёные волосы, пояс и три меча Зоро. Разбойники различаются не только цветом, но и оружием и элементами одежды.

**Сборка:** Docker и GitHub Actions собирают новые клиентские приложения. Необходимо обновить сервер и все компьютеры игроков до одинаковой версии. В текущем LAN-прототипе способности привязаны к временным сетевым ID игроков: если ID изменится, прежние способности могут не восстановиться.


## Новая стрельба и усиление дьявольскими плодами

**ЛКМ — уникальная стрельба героя.** Луффи быстро выпускает чередующиеся резиновые кулаки; каждый третий выстрел — залп из **трёх кулаков (Гатлинг)**. Зоро стреляет более медленной, широкой и пробивающей волной меча; каждый третий выстрел — **две пересекающиеся режущие волны**. Удары, скорость, пробивание и перезарядка рассчитываются сервером, а не клиентом.

**Все 14 плодов влияют и на ЛКМ, и на Q.** Сначала победите охрану острова, заберите плод клавишей **G**, затем выбирайте его **C**. Выбранный плод добавляет особый эффект обычной стрельбе: резина — отбрасывание и ускорение; огонь/магма — поджог; лёд — заморозка; молния — цепной удар; песок/дым — замедление; цветение/нити — удержание; свет — быстрое пробивание; гравитация — притяжение; землетрясение — ударная волна; барьер — короткий щит; яд — отравление. Более высокий уровень плода усиливает эффект. **Q** по-прежнему запускает отдельный мощный приём с собственным откатом. В воде и за штурвалом стрелять и применять плод нельзя.

В HUD показаны герой, тип его стрельбы, выбранный плод и перезарядка Q. В LAN другие игроки видят цветное свечение плода вокруг кулака или волны меча. Автоматический тест проверяет 14 плодов × 2 героя, попадания, статусы, комбо, запрет чужих способностей и синхронизацию.
